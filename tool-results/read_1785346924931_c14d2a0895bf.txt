    98→## Feature 2 — Anti-plagiarism pre-check (internal, before audit)
    99→- Created `src/app/api/ai/plagiarism/route.ts` with 4 detection layers:
   100→  1. **Internal redundancy**: pairwise Jaccard similarity on word-shingles (k=3). Flags pairs ≥ 25% with severity scaled by score. Extracts the longest shared shingle as evidence.
   101→  2. **Boilerplate phrases**: regex detection of 14 French academic clichés ("De nos jours", "Il convient de noter que", "Force est de constater que", etc.).
   102→  3. **Short sections**: flags sections < 80 words as under-developed.
   103→  4. **Unsupported claims** (AI-powered): ZAI call asks the model to find "De nombreuses études montrent que…"-style claims without sources. Best-effort — falls back gracefully on AI failure.
   104→  - Computes `globalSimilarity` as weighted blend (60% avg pairwise + 40% max pairwise), capped to 100.
   105→  - Sorts flags by severity (high → medium → low).
   106→- Created `src/components/iris/plagiarism-view.tsx` — report UI with:
   107→  - Empty state explaining the 4 detection types + disclaimer that this is INTERNAL (doesn't replace Turnitin).
   108→  - Loading spinner.
   109→  - Report view: global similarity banner (color-coded), 4-type breakdown grid, animated flag cards (each with severity badge, type badge, section reference, excerpt block, recommendation), empty-state CTA to audit when no flags.

   470→## 2. Auto-pagination — le texte ne déborde jamais dans la marge
   471→
   472→### Architecture
   473→- Le contentEditable est un flux continu unique. Les "pages A4" sont purement visuelles (background-image tous les 297mm via la classe `.a4-paginated`).
   474→- Pour EMPÊCHER le texte d'entrer dans la marge inférieure (30mm en bas de chaque page), on insère automatiquement des éléments `<div class="iris-page-break iris-page-break-auto" contenteditable="false">` AVANT tout bloc qui déborderait.
   475→- Le `min-height` du "pousseur" est calculé pour que le bloc suivant démarre exactement à `pageBottom + 25mm` (top de la zone de texte de la page suivante).
   476→
   477→### Constantes
   478→- `A4_PAGE_HEIGHT_PX = 1122.52` (297mm en pixels à 96dpi)
   479→- `A4_MARGIN_TOP_PX ≈ 94.49` (25mm)
   480→- `A4_MARGIN_BOTTOM_PX ≈ 113.39` (30mm — la zone INTERDITE au texte)
   481→- `A4_TEXT_ZONE_HEIGHT_PX ≈ 914.65` (242mm = 297 − 25 − 30)
   482→- `PAGINATION_DEBOUNCE_MS = 250` (évite les sauts de curseur pendant la frappe)
   483→
   484→### Fonction `enforceAutoPagination()` (dans `a4-editor.tsx`)
   485→1. **Reset** : supprime tous les `.iris-page-break-auto[data-auto="true"]` existants.
   486→2. **Boucle** (max 50 itérations pour éviter une boucle infinie) :
   487→   - Parcourt les enfants top-level du contentEditable (paragraphes, titres, listes, tableaux, sauts de page manuels, footnotes…).
   488→   - Pour chaque enfant, mesure `childTop` et `childBottom` en pixels via `getBoundingClientRect()` (robuste au scroll et au positionnement).
   489→   - Skip les enfants trop grands (`childHeight > 914.65px` = 242mm) — un bloc indivisible plus grand qu'une page ne peut pas être paginé proprement ; on le laisse déborder (limite connue, l'utilisateur doit le scinder manuellement).
   490→   - Calcule `pageIdx = floor(childTop / 1122.52)`.
   491→   - Calcule `pageTextZoneBottom = (pageIdx + 1) * 1122.52 − 113.39` (limite basse de la zone de texte de la page courante).
   492→   - Calcule `pageBottom = (pageIdx + 1) * 1122.52` (bord bas de la page = bord haut de la page suivante).
   493→   - Deux cas de violation détectés :
   494→     - **crossesTextZone** : `childTop < pageTextZoneBottom` ET `childBottom > pageTextZoneBottom` (le bloc traverse la limite de zone de texte).
   495→     - **startsInMargin** : `childTop >= pageTextZoneBottom` ET `childTop < pageBottom` (le bloc commence déjà dans la marge — cas qui peut arriver au chargement initial ou après un gros changement de contenu).
   496→   - Si violation : insère un `<div class="iris-page-break iris-page-break-auto" contenteditable="false" data-auto="true" aria-hidden="true">` avec `min-height = (pageBottom + 94.49) − childTop` pixels et innerHTML `<span>Page suivante</span>`.
   497→   - `break` puis on recommence la boucle (les positions ont changé après l'insertion).
   498→3. **Final** : `recomputePageCount()` + persistance du HTML modifié via `onChange(newHtml)`.
   499→
   500→### Fonction `scheduleAutoPagination()` (wrapper debounced)
   501→- Annule tout timer précédent, planifie un nouveau passage après 250ms.
   502→- Évite les reflow de page à chaque keystroke — l'utilisateur peut taper fluidement, la pagination se recalule quand il fait une pause.
   503→
   504→### CSS `.iris-page-break-auto` (dans `globals.css`)
   505→- `display: flex; flex-direction: column; justify-content: flex-end` → le label "Page suivante" s'affiche en bas du pousseur (à la limite entre les deux pages).
   506→- `background: repeating-linear-gradient(135deg, transparent, transparent 6px, rgba(124,58,237,0.05) 6px, rgba(124,58,237,0.05) 12px)` → hachures violettes discrètes pour marquer visuellement la zone vide.
   507→- `border-top: 1px dashed rgba(124,58,237,0.45)` → ligne pointillée en haut du pousseur.
   508→- Le `min-height` est fixé inline par le JS (calculé pour pousser jusqu'à la page suivante).
   509→- `@media print` : le pousseur devient invisible (`background: none`, `border: none`, `min-height: 0`, `height: 0`, `overflow: hidden`) MAIS conserve `break-after: page; page-break-after: always` → vrai saut de page à l'impression.
